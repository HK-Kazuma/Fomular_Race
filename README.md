# GOLDEN HOUR GP — No.7

黄昏の砂漠サーキットを舞台にしたフォーミュラレースゲーム（React）。
最後尾10番手からスタートし、3周でトップを目指す。PC・スマホ（縦/横）両対応。

- **3Dモード**（Three.js）：起伏のある3Dコース、手続き生成の3Dマシン、時間経過で沈む夕日と灯る照明、ブルーム・影、
  チェイス / T-CAM / ファーチェイスの3カメラ、タイトルとリザルトはTV中継風カメラ
- **CLASSICモード**（Canvas 2D）：軽快な疑似3D。WebGL2が使えない環境では自動でこちら

## 遊び方

| 操作 | キーボード | スマホ |
| --- | --- | --- |
| ステア | ← → / A D | ◀ ▶ パッド（指を滑らせて切替可） |
| アクセル | ↑ / W | 自動（一時停止メニューで切替） |
| ブレーキ | ↓ / S | BRAKE |
| ブースト（ERS） | Space / Shift | BOOST |
| 一時停止 | Esc / P | Ⅱ ボタン |
| カメラ切替（3D） | C | カメラボタン |
| ミュート | M | 一時停止メニュー |

- **ERS**：ブレーキ・アクセルオフ・スリップストリームで充電、BOOSTで加速と最高速アップ
- **DRS**：DRSゾーンで前車と1秒以内なら自動でフラップが開き、最高速アップ
- **スリップストリーム**：前車の真後ろで加速とERS充電が増える
- コーナーでは遠心力で外へ流される。縁石の外はグラベルで失速、壁に当たると大幅ロス
- 難易度：ROOKIE / PRO / LEGEND。実績10種と難易度別ベスト記録は localStorage に保存

## 開発

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # dist/ に通常ビルド
npm run build:single # dist-single/index.html に1ファイルビルド（そのまま配布可）
```

## 構成

```
src/
  App.jsx                 画面遷移（タイトル / レース / リザルト）とエンジン接続
  game/engine.js          シミュレーション（物理・ライバルAI・ラップ/順位）＋疑似3D描画
  game3d/engine3d.js      Engineを継承し描画だけThree.jsに差し替え（カメラ・パーティクル・ポストエフェクト）
  game3d/world.js         曲率から3D中心線を復元し、路面・縁石・壁・スタンド・照明塔・空を生成
  game3d/car3d.js         プリミティブとロフトで組み立てる3Dマシン（DRSフラップ・ホイール回転・レインライト）
  game3d/textures.js      路面・砂・広告・フェンスなどのテクスチャをCanvasで生成
  game/track.js           サーキット定義（セグメント列・DRSゾーン・沿道オブジェクト・ミニマップ）
  game/art.js             マシン/スタンド/照明塔/背景を手続き生成で描画
  game/audio.js           WebAudioでエンジン音・風切り音・効果音を合成
  game/progress.js        実績と自己ベストの保存
  components/             HUD・タッチ操作・タイトル・リザルト・ポーズ
```

画像・音声・3Dモデルファイルは使わず、すべてコードで生成しています。2D/3Dは同じシミュレーションを共有しているので、難易度や実績は共通です。チーム名・ロゴ・キャラクターはオリジナルです。
